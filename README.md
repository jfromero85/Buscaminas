# Buscaminas Neo

Juego básico estilo buscaminas con una estética futurista (neón + glassmorphism), hecho con HTML, CSS y JavaScript vanilla.

## Cómo ejecutarlo

Abre `index.html` directamente en el navegador o levanta un servidor local:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.
